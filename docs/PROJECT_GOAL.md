# Project Goal: Bayesian Analysis of FRB 20191221A

## Overview
This project aims to develop a comprehensive Bayesian framework for modeling Fast Radio Burst FRB 20191221A, a repeating FRB exhibiting sub-second periodicity.

## Background
FRB 20191221A is a repeating fast radio burst characterized by:
- Sub-second periodic structure
- Multiple mini-pulses (n pulses) that combine to form a broadened signal
- Currently modeled using 9 pulses with exponentially modified Gaussian (EMG) profiles

## Research Objectives

### Phase 1: Advanced Bayesian Analysis
- **Pulse Number Estimation**: Develop methods to estimate the true number of pulses in the signal using Bayesian inference
- **Model Comparison**: Implement and compare different pulse models:
  - Periodic sums of exponentially modified Gaussians (EMG)
  - Periodic exponential pulses
  - Direct comparison between EMG and exponential models
- **Model Selection**: Use Bayesian evidence to quantitatively evaluate and select the best-fitting models

### Phase 2: Physical Interpretation
- Interpret the statistical results in the context of FRB emission physics
- Connect model parameters to potential astrophysical mechanisms
- Explore implications for the nature of the FRB source

## Current Status
The project has established a basic analysis framework identifying 9 pulses using EMG profiles. The next steps involve implementing more sophisticated Bayesian methods to:
1. Determine the optimal number of pulses
2. Test alternative pulse models
3. Provide robust statistical evidence for model selection

## Expected Outcomes
- A rigorous statistical framework for FRB pulse modeling
- Quantitative model comparison using Bayesian evidence
- Physical insights into the emission mechanism of FRB 20191221A
- Generalizable methods applicable to other repeating FRBs
